Una imagen de 3×3 tiene nueve píxeles

En esta imagen didáctica, cada píxel tiene tres canales de 8 bits. R indica rojo, G verde y B azul. Cada canal va de 0 a 255.

Cómo comparar dos colores con la distancia euclidiana

Cada característica es una dimensión. En RGB hay tres: un punto como P5 = (161, 121, 53) tiene una coordenada para R, otra para G y otra para B. La fila y la columna solo ubican ese color en la imagen.

La distancia euclidiana funciona con una, dos, tres, cuatro, cien o miles de características. Compara dos vectores del mismo tamaño y suma un cuadrado por dimensión.

DimensionesCaracterísticas de ejemploFórmula
1R|ΔR|
2R, G√(ΔR² + ΔG²)
3R, G, B√(ΔR² + ΔG² + ΔB²)
4R, G, B, tamaño√(ΔR² + ΔG² + ΔB² + Δtamaño²)
nx₁, x₂, …, xₙ√(Δx₁² + Δx₂² + ⋯ + Δxₙ²)

Δ significa diferencia. Si mezclas medidas en escalas o unidades distintas, considera ajustar las escalas antes de calcular la distancia.

Ejemplo resuelto · ¿Qué tan parecido es P5 a P2?

Busca P5 en la fila 2, columna 2, y P2 en la fila 1, columna 2. Copia el RGB de cada celda. Compara rojo con rojo, verde con verde y azul con azul.

CanalP5P2DiferenciaDiferencia al cuadrado
R161127161 − 127 = 3434² = 1156
G121118121 − 118 = 33² = 9
B533353 − 33 = 2020² = 400

Al elevar las diferencias al cuadrado, todas contribuyen sin cancelarse. Suma 1156 + 9 + 400 = 1565 y saca la raíz cuadrada. La distancia entre los dos colores es √1565 ≈ 39.56.

Para decidir qué color está más cerca de P5, necesitamos otra distancia. Al comparar P5 con P1 obtenemos √(64² + 13² + 48²) ≈ 81.05. Como 39.56 < 81.05, P5 se parece más a P2 que a P1 según RGB. En la primera ronda de K-means esto favorece a G2 porque su centro inicial es P2. KNN usa esta misma operación para ordenar sus seis referencias antes de votar.

Ver en Python las operaciones de K-means y KNN
from collections import Counter
from math import dist

# K-means. K=2 grupos. El ajuste utiliza los nueve vectores RGB.
centros = [vectores[0], vectores[1]]
while True:
    grupos = [min(range(2), key=lambda i: dist(rgb, centros[i]))
              for rgb in vectores]
    nuevos = []
    for grupo, centro in enumerate(centros):
        miembros = [rgb for rgb, asignacion in zip(vectores, grupos)
                    if asignacion == grupo]
        promedio = [sum(canal) / len(miembros)
                    for canal in zip(*miembros)] if miembros else centro
        nuevos.append(promedio)
    if nuevos == centros:
        break
    centros = nuevos

print("Centroides:", centros)
print("Grupos P1 a P9:", [f"G{grupo + 1}" for grupo in grupos])

# KNN. K=3 vecinos. Solo compara contra las referencias etiquetadas.
referencias = [(0, 'Inmadura'), (1, 'Inmadura'), (2, 'Madura'), (3, 'Inmadura'), (5, 'Madura'), (8, 'Madura')]
consultas = [4, 6, 7]
k = 3
for indice in consultas:
    consulta = vectores[indice]
    # Si hay dos distancias iguales, primero va el P de menor número.
    orden = sorted(referencias, key=lambda ejemplo: (
        dist(consulta, vectores[ejemplo[0]]), ejemplo[0]))
    vecinos = orden[:k]
    votos = Counter(etiqueta for _, etiqueta in vecinos)
    print(f"P{indice + 1} RGB {consulta}: {votos.most_common(1)[0][0]}",
          "con votos", dict(votos))

Aprendizaje no supervisado

K-means encuentra grupos de color

K-means se ajusta con los nueve vectores RGB de la imagen, incluido P5. Aquí fijamos K = 2 grupos y usamos los vectores de P1 y P2 como centroides iniciales. Pulsa Siguiente paso para ver cómo se asignan las muestras y se mueven los centros.

Qué calcula cada paso

Asignar. Calcula √(ΔR² + ΔG² + ΔB²) entre cada muestra y cada centroide. La menor distancia decide el grupo.

Recalcular. El nuevo centroide es (promedio de R, promedio de G, promedio de B) de las muestras asignadas. Por ejemplo, si un grupo contiene únicamente P1 (97, 108, 5) y P2 (127, 118, 33), su centroide es ((97 + 127)/2, (108 + 118)/2, (5 + 33)/2) = (112, 113, 19).

Centroides finales. G1 = [90.75, 96.0, 11.25], G2 = [200.4, 101.6, 69.4]

P5 [161, 121, 53] y los centroides finales

Distancia a G1 √((161 − 90.75)² + (121 − 96)² + (53 − 11.25)²) ≈ 85.46

Distancia a G2 √((161 − 200.4)² + (121 − 101.6)² + (53 − 69.4)²) ≈ 46.88

Seguir a P5 en las tres rondas

Cada ronda compara todos los colores con los dos centros y luego vuelve a calcular los promedios. Los números que ves se muestran con hasta dos decimales. El algoritmo usa la precisión completa.

Ronda 1

Comparación de P5. G1 [97, 108, 5], distancia 81.05. G2 [127, 118, 33], distancia 39.56. P5 queda en G2 porque su distancia es menor.

En esta ronda G1 reúne P1, P4 y P7. Para actualizar su centroide, promedia cada canal de esas tres muestras. R = (97 + 79 + 60) ÷ 3 ≈ 78.67, G = (108 + 89 + 69) ÷ 3 ≈ 88.67 y B = (5 + 4 + 3) ÷ 3 = 4. Aplica el mismo procedimiento a las seis muestras de G2.

Centroides después del promedio. G1 = [78.67, 88.67, 4] y G2 = [188.17, 104.33, 63.33].

Ronda 2

Comparación de P5. G1 [78.67, 88.67, 4], distancia 101.12. G2 [188.17, 104.33, 63.33], distancia 33.50. P5 queda en G2 porque su distancia es menor.

Con los nuevos centros se repite la comparación para los nueve puntos. P2 pasa de G2 a G1. P5 sigue en G2, pero cambian los promedios de ambos grupos porque P2 ahora contribuye al promedio de G1.

Centroides después del promedio. G1 = [90.75, 96, 11.25] y G2 = [200.4, 101.6, 69.4].

Ronda 3

Comparación de P5. G1 [90.75, 96, 11.25], distancia 85.46. G2 [200.4, 101.6, 69.4], distancia 46.88. P5 queda en G2 porque su distancia es menor.

Las asignaciones coinciden con las de la ronda 2. Al promediar otra vez se obtienen los mismos centros. Aquí termina el ajuste y se guardan los dos centroides.

Centroides después del promedio. G1 = [90.75, 96, 11.25] y G2 = [200.4, 101.6, 69.4].

Cómo leer el resultado de K-means

Al final, G1 reúne P1, P2, P4 y P7, con centroide (90.75, 96, 11.25). G2 reúne P3, P5, P6, P8 y P9, con centroide (200.4, 101.6, 69.4). El mapa pinta todas las muestras de un grupo con el RGB de su centroide. G1 y G2 indican semejanza de color. Si llega un RGB nuevo, puedes asignarlo al centroide final más cercano usando el modelo guardado.

  1. Inicializa. Toma los RGB de P1 y P2 como centros iniciales.
  2. Asigna. Para cada píxel calcula la distancia euclidiana a ambos centros: √(ΔR² + ΔG² + ΔB²). Conserva el grupo del centro más cercano.
  3. Recalcula. Promedia R, G y B por separado dentro de cada grupo. Observa los números del promedio en el paso de actualización.
  4. Repite. Vuelve a asignar y promediar hasta que los centros dejen de moverse. Los centroides finales son los parámetros aprendidos. Tú elegiste el número de grupos.

Cómo leer el resultado de KNN

Con K = 1, P5 se clasifica como «Inmadura» porque solo vota P2. Con K = 3, también votan P3 y P6, ambos «Madura». El resultado cambia a «Madura» por dos votos a uno. El asterisco del mapa identifica las predicciones. Para consultar un RGB nuevo se repite el cálculo contra las mismas seis referencias.

  1. Conserva las referencias. KNN guarda los RGB de los seis ejemplos y sus etiquetas.
  2. Calcula. Compara el RGB del píxel de consulta con el de cada ejemplo mediante la misma distancia euclidiana del apartado anterior.
  3. Ordena y vota. Toma los K ejemplos más cercanos. La etiqueta con más votos es la predicción. Prueba K=1, 3 y 5 con P5 para observar cómo cambia el voto.

Ver código del ejercicio
import json
from collections import Counter
from math import dist
from pathlib import Path

# Cambia este vector para probar otro color.
muestra = [150, 115, 45]
carpeta = Path(__file__).resolve().parent

with (carpeta / "modelo_kmeans.json").open(encoding="utf-8") as archivo:
    kmeans = json.load(archivo)

with (carpeta / "modelo_knn.json").open(encoding="utf-8") as archivo:
    knn = json.load(archivo)

print("Consulta RGB:", muestra)
print("\nK-means. Distancias a los centroides guardados:")
centroides = kmeans["centroides"]
for centro in centroides:
    distancia = dist(muestra, centro["rgb"])
    print(f'  {centro["grupo"]} {centro["rgb"]}: {distancia:.2f}')
centro_cercano = min(centroides, key=lambda centro: dist(muestra, centro["rgb"]))
print("Grupo asignado:", centro_cercano["grupo"])

k = knn["k"]
referencias = knn["referencias"]
ordenadas = sorted(referencias, key=lambda ref: dist(muestra, ref["rgb"]))
vecinos = ordenadas[:k]

print(f"\nKNN. Referencias que votan con K = {k}:")
for vecino in vecinos:
    distancia = dist(muestra, vecino["rgb"])
    print(f'  {vecino["pixel"]} {vecino["etiqueta"]}: {distancia:.2f}')
votos = Counter(vecino["etiqueta"] for vecino in vecinos)
print("Votos:", dict(votos))
print("Clase predicha:", votos.most_common(1)[0][0])


    
Comprobar después de hacer la operación
      
Para [150, 115, 45], la distancia a G1 es 70.79 y a G2 es 57.58. K-means asigna G2 porque está más cerca. En KNN votan P2, P1 y P3. Gana Inmadura por dos votos a uno con K = 3.
