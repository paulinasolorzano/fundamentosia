Tu escuela organizará una feria tecnológica. Hay 10 unidades de presupuesto. Debes elegir qué proyectos financiar para obtener el mayor beneficio.

LetraProyectoCostoBeneficio
AEstación meteorológica35
BRiego automático48
CExposición digital23
DPrototipo de dron59

Es parecido al ejemplo de Huerto y Robótica, pero los datos son diferentes. No copies sus resultados.

Orden fijo: A, B, C, D. 1 = incluir, 0 = no incluir. Por ejemplo, 1000 elige solo A: cuesta 3, aporta 5 y recibe 5 puntos.
Si el costo supera 10, la puntuación es 0; si no, es igual al beneficio.

1. Evaluación inicial

CódigoProyectosCostoBeneficioPuntuación
1100A+B71313
1000A355
0011C+D71212
1010A+C588

2. Selección

1100 gana a 1000 (13 contra 5). 0011 gana a 1010 (12 contra 8). Padres: 1100 y 0011.

3. Cruce

11|00 + 00|11 → 1111 y 0000

1111 cuesta 14, aporta 25 y obtiene 0 puntos por exceder el presupuesto. 0000 cuesta 0, aporta 0 y obtiene 0 puntos. Tiene presupuesto válido, pero no aporta beneficio. Los dos hijos empeoran las propuestas seleccionadas.

4. Mutación del primer hijo

1111 → 1110. Se retira D. Costo 3+4+2 = 9. Beneficio 5+8+3 = 16. Puntuación 16.

5. Nueva generación

1100, 0011, 1110, 0000. Puntuaciones: 13, 12, 16, 0. La mejor pasa de 13 a 16. Guardamos las dos mejores originales y añadimos el primer hijo mutado y el segundo sin cambios.

Explicación esperada

El cruce no garantiza una mejora: un hijo excedió el presupuesto y el otro no eligió proyectos. La mutación eliminó el dron, redujo el costo y volvió válida la propuesta. El cambio fue preparado para enseñar; una mutación aleatoria podría ayudar o perjudicar. La mejora de esta generación no demuestra que se haya encontrado el óptimo global.

"""Solución docente. Python 3, sin paquetes externos. Recorrido fijo para aprender."""
COSTOS = [3, 4, 2, 5]
BENEFICIOS = [5, 8, 3, 9]
PRESUPUESTO = 10


def evaluar(codigo):
    costo = 0
    beneficio = 0
    for i in range(4):
        if codigo[i] == "1":
            costo += COSTOS[i]
            beneficio += BENEFICIOS[i]
    puntos = beneficio if costo <= PRESUPUESTO else 0
    return costo, beneficio, puntos


def torneo(a, b):
    if evaluar(b)[2] > evaluar(a)[2]:
        return b
    return a


def cruzar(a, b):
    return a[:2] + b[2:], b[:2] + a[2:]


def mutar_ultima(codigo):
    nueva = "0" if codigo[3] == "1" else "1"
    return codigo[:3] + nueva


if __name__ == "__main__":
    poblacion = ["1100", "1000", "0011", "1010"]
    print("Inicial (costo, beneficio, puntuación):")
    for propuesta in poblacion:
        print(propuesta, evaluar(propuesta))
    padre1 = torneo(poblacion[0], poblacion[1])
    padre2 = torneo(poblacion[2], poblacion[3])
    print("Padres:", padre1, padre2)
    hijo1, hijo2 = cruzar(padre1, padre2)
    print("Hijos:", hijo1, evaluar(hijo1), hijo2, evaluar(hijo2))
    mutado = mutar_ultima(hijo1)
    print("Primer hijo mutado:", mutado, evaluar(mutado))
    elites = sorted(poblacion, key=lambda c: evaluar(c)[2], reverse=True)[:2]
    nueva = elites + [mutado, hijo2]
    print("Nueva población:", nueva)
    print("Mejor puntuación:", max(evaluar(c)[2] for c in nueva))
