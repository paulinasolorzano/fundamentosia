# Práctica sencilla de algoritmos genéticos
Abre index.html en tu navegador. Funciona sin internet y no necesita instalaciones.
Incluye dos ejemplos completos y controles para probar propuestas.

1. Lee el ejemplo de proyectos antes del vocabulario técnico.
2. Continúa con el fragmento de horario escolar.
3. Resuelve ACTIVIDAD_ALUMNO.md. Las respuestas están plegadas en la página.
4. Python es opcional: ejecuta ejemplos_paso_a_paso.py con Python 3.

La carpeta original conserva sin cambios los seis archivos proporcionados.
No se han modificado los archivos del Escritorio.
Las decisiones del recorrido se fijan para enseñar; no simulan una búsqueda aleatoria completa.
