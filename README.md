# Invernadero IA

Página web educativa para practicar lógica proposicional, reglas e inferencias mediante un sistema de IA simbólica.

## Contenido

- Simulador interactivo de sensores.
- Proposiciones verdaderas y falsas en tiempo real.
- Cinco reglas de inferencia encadenadas.
- Explicación paso a paso de las conclusiones.
- Cinco casos de prueba.
- Reto para ampliar y programar nuevas reglas.

## Ejecutar localmente

No requiere instalar dependencias. Abre `index.html` en un navegador o utiliza la extensión Live Server de Visual Studio Code.

## Publicar con GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `styles.css`, `script.js` y `README.md` a la raíz del repositorio.
3. En el repositorio abre **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main`, la carpeta `/root` y guarda.
6. GitHub mostrará la dirección pública cuando termine la publicación.

## Tecnología

HTML, CSS y JavaScript, sin bibliotecas externas de programación.
