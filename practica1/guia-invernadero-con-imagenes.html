¿Qué vas a construir?

Una página con cinco casillas, un botón Evaluar reglas y un área de resultados. Una casilla marcada representa verdadero; una casilla sin marcar, falso. Los resultados se muestran en la página, no en la consola.

Usaremos las cinco reglas de la práctica del invernadero. Para concentrarnos en la lógica, sustituimos los sensores numéricos por proposiciones que tú marcas. Por ejemplo, marcar P equivale a afirmar que la humedad está por debajo del 30 %.

Tu trabajo será programar. La interfaz y una regla sirven como ejemplo. Tú escribirás las otras cuatro reglas, comprobarás casos y agregarás una regla con disyunción. La base descargable está incompleta a propósito.

Descargar base opcional: solo los dos archivos. Si tu docente pide escribir desde cero, sigue los pasos y transcribe el código.

1. Prepara tus dos archivos

  1. Crea una carpeta llamada invernadero.
  2. Ábrela en Visual Studio Code con Archivo → Abrir carpeta.
  3. Crea index.html y script.js dentro de esa misma carpeta.
  4. Guarda los cambios y abre index.html en tu navegador con doble clic. No necesitas servidor ni instalar extensiones.
Para ejecutar: descomprime la base y abre index.html en Chrome, Edge o Firefox. Mantén script.js en esa misma carpeta. Una vista previa de archivos puede no ejecutar JavaScript. El mensaje “JavaScript cargado” confirma que la conexión funciona.

HTML contiene la interfaz; JavaScript contiene las reglas. Bootstrap solo mejora la presentación y se carga desde internet. Sin conexión, la actividad seguirá funcionando con la apariencia básica del navegador. Esta guía también se puede leer sin internet.

5. Tu turno: escribe las otras cuatro reglas

Agrega un bloque if/else por regla debajo de R1 y antes de mostrar resultados. En cada if cambia la conclusión correspondiente a true y agrega un mensaje. En cada else informa que esa regla no se activa.

ReglaFórmulaConclusión que debes registrar
R2(A ∧ S) → BActivar riego.
R3(A ∧ ¬S) → EGenerar alerta por agua insuficiente.
R4Q → CSe necesita ventilación.
R5(C ∧ ¬T) → DAbrir ventana.

Pistas: traduce ∧ con && y ¬ con !. En R4 basta una variable como condición. Usa A y C, porque son conclusiones obtenidas por reglas anteriores.

Conserva el orden R1 → R2 → R3 → R4 → R5. R2 y R3 necesitan el resultado de R1; R5 necesita el de R4. Usa cinco if independientes, cada uno con su else: un else if entre todas las reglas impediría obtener varias conclusiones en una evaluación.

El sistema revisa las cinco reglas y activa solo las que cumplen su condición. Esta versión usa una sola pasada en orden; no es un motor que busque automáticamente el orden de cualquier regla nueva.

Fidelidad a las reglas: si hace calor y hay una persona, concluye que se necesita ventilación, pero no abrir la ventana. No agregues “ventilar manualmente” salvo que redactes y programes una regla adicional que lo indique.

¿Dónde está la IA? En la representación de hechos y reglas que permite derivar conclusiones. Es un ejemplo sencillo de IA simbólica. El programa no aprende solo ni controla equipos reales: simula decisiones.

Si algo falla

No cambia el resultado: revisa que el archivo se llame script.js, que esté junto a index.html y que la función se llame evaluar. Una casilla no funciona: revisa que su id coincida con getElementById. Faltan conclusiones: revisa el orden y las llaves. Guarda ambos archivos y recarga el navegador después de editar.
