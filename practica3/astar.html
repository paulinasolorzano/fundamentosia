1. Primero entiende el dibujo

Queremos ir de A, la entrada, a G, la biblioteca. Hay dos caminos principales: uno pasa por C y otro pasa por B, D, E y F.

Los círculos son nodos

Cada letra identifica un lugar. A y C son dos nodos distintos. En este ejemplo no necesitas saber las coordenadas de esos lugares.

Las líneas son conexiones

Una línea entre A y C indica que puedes ir de uno al otro. El nombre formal de esa línea es arista.

Todo el dibujo es un grafo

Un grafo reúne nodos y conexiones. Como las líneas no tienen flechas, puedes moverte en ambos sentidos.

Un camino une el inicio y la meta

A → C → G es un camino. Tiene tres nodos y dos conexiones. La posición inicial no cuenta como movimiento.

Cada conexión vale 1. Una línea larga y una corta valen lo mismo: este dibujo muestra qué lugares están conectados, no las distancias reales.

¿Por qué le llamamos grafo y no árbol de decisión?

Este grafo tiene caminos que se vuelven a unir y puede tener ciclos: B → D → H → B permite volver al punto de partida.

Un árbol no tiene ciclos. Un árbol de búsqueda muestra cómo se abren las alternativas desde el inicio. Un árbol de decisión es otro modelo, por ejemplo para clasificar mediante preguntas. Aquí usaremos la palabra grafo.

Antes de seguir: señala un nodo, una conexión y la meta. Cuenta las conexiones de A → B → D → E → F → G.

2. A*, explicado paso a paso

Imagina que un personaje de videojuego quiere alcanzar un refugio. Tiene varias opciones, pero también una pista sobre cuánto podría faltar desde cada lugar.

A* suma dos números:

Lo recorrido + lo que calcula que falta = número para decidir

Los libros usan letras: g es lo recorrido; h es la pista sobre lo que falta; f es la suma.

Hagamos la primera decisión juntos

Desde A puede avanzar a B o a C. Llegar a cualquiera cuesta una conexión.

OpciónYa recorrido: gPista: hSuma: f
B134
C112

Elige C porque 2 es menor que 4. Desde C descubre G. Llegar a G cuesta dos conexiones y allí ya no falta nada: 2 + 0 = 2.

G tiene mejor suma que B, así que revisa G y termina: A → C → G.

La pista es una estimación. No es una promesa de que haya un camino directo. A* conserva otras opciones para usarlas si hace falta.

¿Quién inventa los números de la pista?

La persona que diseña el programa elige una forma de estimar. En un videojuego podría usar la distancia en línea recta, sin contar todavía los obstáculos.

Para esta práctica ya preparamos los números: A=2, B=3, C=1, D=3, E=2, F=1, G=0 y H=4. No debes obtenerlos midiendo las líneas del dibujo. Son pistas didácticas que no exageran lo que falta.

¿Cuándo te conviene?

Cuando buscas una ruta y tienes una pista útil para orientar la búsqueda. En este ejemplo encuentra una ruta de costo mínimo.

La calidad de la pista importa. Si exagera demasiado lo que falta, puede perder la garantía de encontrar la mejor ruta. A* no siempre revisa menos nodos que BFS.

Esta lista puede ser diferente del camino final. El programa prueba posibilidades en su memoria; el personaje recorrería después el camino encontrado.

¿Cómo recuerda el programa el camino?

Para cada nodo nuevo guarda desde dónde llegó. Por ejemplo: llegó a C desde A y llegó a G desde C. Al terminar, sigue esas notas hacia atrás y obtiene A → C → G.

¿Cómo guarda las conexiones?

Con una lista de vecinos. "A": ["B", "C"] significa que desde A se puede ir directamente a B y a C.

Para que el ejemplo se repita igual, usamos las letras en orden alfabético. En DFS las apilamos al revés para que la letra menor quede arriba. En A* comparamos primero la suma; si empatan, lo recorrido y después la letra.


4. ¿En qué situaciones sirve?
Los nodos no siempre son lugares. También pueden ser personas o situaciones de un juego. Estos son ejemplos de aplicación del algoritmo o de sus variantes.
Un enemigo de videojuego que rodea una pared
La situación: Un personaje quiere acercarse al jugador, pero no puede atravesar edificios.
Cómo lo representamos: Cada zona transitable es un nodo. Las conexiones son movimientos permitidos. A* combina el costo recorrido con una estimación de lo que falta.
Para qué sirve: Sirve para planear una ruta alrededor de obstáculos. Si el jugador se mueve, el juego puede necesitar calcularla otra vez.
Un robot que lleva tu pedido por un almacén
La situación: Un robot debe ir a recoger un producto sin atravesar las estanterías.
Cómo lo representamos: Los puntos del mapa son nodos; los pasillos son conexiones. A* puede buscar una ruta hacia el producto.
Para qué sirve: Es una forma posible de planear rutas. Evitar otros robots o personas exige mecanismos adicionales.


5. ¿Qué tiene que ver con la IA?
Un programa necesita elegir acciones para llegar a una meta. En vez de adivinar, representa las opciones y las explora con una regla.
A* pertenece a la búsqueda y resolución de problemas dentro de la IA clásica.
Su categoría es búsqueda informada: usa una pista para estimar lo que falta.
Esto puede ayudar a planear acciones en juegos o robots. El algoritmo no aprende de ejemplos: ejecuta reglas de búsqueda. También se utiliza en informática fuera de la IA.


6. Del dibujo al código Python
No tienes que inventar todo el programa. El botón Generar código prepara un ejemplo completo con las conexiones que tienes abiertas ahora.
  1. Vuelve a «Todos los caminos abiertos».
  2. Pulsa «Generar código». Mira primero la lista llamada grafo: las letras representan los nodos del dibujo.
  3. Descarga el archivo. Necesitas Python 3 para ejecutarlo.
  4. Compara el camino que imprime con el que viste en el simulador.
Las palabras del código, sin complicaciones
  • grafo: guarda quién está conectado con quién.
  • pendientes: guarda los nodos que esperan ser revisados.
  • anterior: recuerda desde dónde llegamos a cada nodo.
  • buscar: es la función que intenta encontrar un camino.
  • reconstruir: recupera el camino usando las notas guardadas.
  • None: indica que no se encontró un camino.
mejor recuerda el menor costo encontrado para llegar a un nodo. heuristica guarda las pistas. heapq ayuda a sacar la opción con la menor suma.
Cómo ejecutar el archivo
  1. Instala Python 3 desde su página oficial si todavía no lo tienes.
  2. Guarda el archivo descargado en una carpeta y abre una terminal en esa carpeta.
  3. En Windows escribe py astar_practica.py. En macOS o Linux escribe python3 astar_practica.py. Pulsa Enter.
  4. Si no encuentra el archivo, revisa que la terminal esté en la carpeta donde lo guardaste.
La página muestra una simulación. El programa Python se ejecuta en tu equipo.
