¿Cómo encuentra un programa un camino?

Hay varias maneras de buscar. Vamos a entender tres usando el mismo dibujo.

No necesitas conocer estas siglas. Empieza por BFS y sigue en orden. Cada práctica explica el vocabulario, muestra las decisiones y prepara un programa pequeño.

Antes de empezar

Un círculo representa un lugar y se llama nodo. Una línea indica que dos lugares están conectados y se llama arista. El dibujo completo se llama grafo.

Queremos ir de A a G. A → C → G usa dos conexiones. A → B → D → E → F → G usa cinco. Los tres algoritmos ven el mismo grafo, pero eligen qué revisar con reglas diferentes.

¿Por qué estudiamos esto en IA?

Porque un programa necesita explorar alternativas para alcanzar una meta. Estos algoritmos pertenecen a búsqueda y resolución de problemas en la IA clásica.

BFS y DFS buscan sin estimar lo que falta. A* utiliza una pista. Ninguno necesita aprender de datos para funcionar.
