DFS: seguir una posibilidad hasta el final

Elige un camino y sigue explorándolo. Cuando no quedan opciones nuevas, retoma otra posibilidad que dejó pendiente.

Al terminar podrás explicar cómo decide, reconocer un uso real y ejecutar un programa pequeño.

1. Primero entiende el dibujo

Queremos ir de A, la entrada, a G, la biblioteca. Hay dos caminos principales: uno pasa por C y otro pasa por B, D, E y F.

Los círculos son nodos

Cada letra identifica un lugar. A y C son dos nodos distintos. En este ejemplo no necesitas saber las coordenadas de esos lugares.

Las líneas son conexiones

Una línea entre A y C indica que puedes ir de uno al otro. El nombre formal de esa línea es arista.

Todo el dibujo es un grafo

Un grafo reúne nodos y conexiones. Como las líneas no tienen flechas, puedes moverte en ambos sentidos.

Un camino une el inicio y la meta

A → C → G es un camino. Tiene tres nodos y dos conexiones. La posición inicial no cuenta como movimiento.

Cada conexión vale 1. Una línea larga y una corta valen lo mismo: este dibujo muestra qué lugares están conectados, no las distancias reales.

¿Por qué le llamamos grafo y no árbol de decisión?

Este grafo tiene caminos que se vuelven a unir y puede tener ciclos: B → D → H → B permite volver al punto de partida.

Un árbol no tiene ciclos. Un árbol de búsqueda muestra cómo se abren las alternativas desde el inicio. Un árbol de decisión es otro modelo, por ejemplo para clasificar mediante preguntas. Aquí usaremos la palabra grafo.

Antes de seguir: señala un nodo, una conexión y la meta. Cuenta las conexiones de A → B → D → E → F → G.

2. DFS, explicado paso a paso

Imagina que exploras un escape room. En lugar de revisar un poco de cada zona, sigues una posibilidad para ver hasta dónde llega.

DFS guarda las opciones como una pila de platos: toma primero lo último que puso encima. En programación se llama pila.

  1. Comienza en A. Guarda C y después B. B queda encima: se revisará primero.
  2. Revisa B. Guarda H y después D. D queda encima.
  3. Revisa D. Descubre E. H ya estaba guardado: no lo agrega otra vez.
  4. Revisa E, después F y después G. Ha seguido una rama hasta encontrar la meta.
  5. El camino encontrado es A → B → D → E → F → G. Tiene cinco conexiones.

Había una ruta de dos conexiones, A → C → G. DFS encontró primero una solución más larga. Encontrar una solución no significa encontrar la más corta.

Para observar qué pasa cuando no encuentra la meta, prueba «Biblioteca aislada». Verás que termina una rama y retoma los nodos que había dejado pendientes.

¿Cuándo te conviene?

Cuando quieres explorar posibilidades y no necesitas que la primera solución tenga el menor número de pasos.

En este grafo pequeño, si existe una ruta la encontrará. Recordar los nodos que ya descubrió evita repetirlos sin parar.

¿Cómo recuerda el programa el camino?

Para cada nodo nuevo guarda desde dónde llegó. Por ejemplo: llegó a C desde A y llegó a G desde C. Al terminar, sigue esas notas hacia atrás y obtiene A → C → G.

¿Cómo guarda las conexiones?

Con una lista de vecinos. "A": ["B", "C"] significa que desde A se puede ir directamente a B y a C.

Para que el ejemplo se repita igual, usamos las letras en orden alfabético. En DFS las apilamos al revés para que la letra menor quede arriba. En A* comparamos primero la suma; si empatan, lo recorrido y después la letra.


4. ¿En qué situaciones sirve?
Los nodos no siempre son lugares. También pueden ser personas o situaciones de un juego. Estos son ejemplos de aplicación del algoritmo o de sus variantes.
Resolver un sudoku probando y regresando
La situación: Pruebas un número en una casilla y continúas. Si llegas a una contradicción, regresas y pruebas otro número.
Cómo lo representamos: Cada tablero parcial es un nodo. Colocar un número válido abre una nueva posibilidad. La búsqueda profundiza en esas decisiones.
Para qué sirve: La técnica de retroceso puede organizarse como una búsqueda en profundidad. También necesita las reglas del sudoku; el código de abajo solo busca caminos.
Crear un laberinto diferente en cada partida
La situación: Quieres generar los pasillos de un juego para que no siempre sean iguales.
Cómo lo representamos: Cada celda es un nodo. Una variante de DFS elige al azar una celda nueva, abre un paso y continúa. Si no puede seguir, regresa.
Para qué sirve: Sirve para construir laberintos. Generarlo es una tarea distinta de encontrar después la salida.


5. ¿Qué tiene que ver con la IA?
Un programa necesita elegir acciones para llegar a una meta. En vez de adivinar, representa las opciones y las explora con una regla.
DFS pertenece a la búsqueda y resolución de problemas dentro de la IA clásica.
Su categoría es búsqueda no informada: no usa una pista sobre lo que falta.
Esto puede ayudar a planear acciones en juegos o robots. El algoritmo no aprende de ejemplos: ejecuta reglas de búsqueda. También se utiliza en informática fuera de la IA.

# DFS · Buscar de A a G en un grafo no dirigido.
# Cada conexión cuesta 1. Los vecinos se consideran alfabéticamente.
def reconstruir(anterior, nodo):
    ruta = []
    while nodo is not None:
        ruta.append(nodo)
        nodo = anterior[nodo]
    return ruta[::-1]


def buscar(grafo, inicio, meta):
    pendientes = [inicio]
    descubiertos = {inicio}
    anterior = {inicio: None}
    while pendientes:
        actual = pendientes.pop()
        if actual == meta:
            return reconstruir(anterior, actual)
        # Apilar al revés permite explorar primero la letra menor.
        for vecino in sorted(grafo[actual], reverse=True):
            if vecino not in descubiertos:
                descubiertos.add(vecino)
                anterior[vecino] = actual
                pendientes.append(vecino)
    return None

Las palabras del código, sin complicaciones
  • grafo: guarda quién está conectado con quién.
  • pendientes: guarda los nodos que esperan ser revisados.
  • anterior: recuerda desde dónde llegamos a cada nodo.
  • buscar: es la función que intenta encontrar un camino.
  • reconstruir: recupera el camino usando las notas guardadas.
  • None: indica que no se encontró un camino.
descubiertos evita guardar repetidamente el mismo nodo. append pone una opción encima de la pila y pop saca la de arriba.
