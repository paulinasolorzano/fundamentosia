02 / Comprender antes de programar

Una red aprende patrones.
No entiende como una persona.

Una red neuronal artificial conecta unidades de cálculo. Durante el entrenamiento ajusta números internos para que sus respuestas se acerquen a los ejemplos.

ENTRADA

Los datos que recibe

Por ejemplo: píxeles de una imagen, medidas de un sensor o valores que describen un mensaje.

PESOS Y SESGO

Lo que se ajusta

Los pesos multiplican las entradas. El sesgo desplaza el punto a partir del cual cambia la decisión.

SALIDA

La respuesta calculada

Una clase, una cantidad o una puntuación. Depende de la tarea y de cómo se diseñó el modelo.

En la parte práctica usaremos un perceptrón: una sola neurona con salida 0 o 1. Es un modelo introductorio; las redes modernas suelen conectar muchas neuronas en varias capas.
Ejemplo + respuesta esperada → Predicción → Error → Ajuste

Entrenar es ajustar los parámetros. Predecir es usarlos, ya fijados, para responder.

Problema → Datos de ejemplo → Aprendizaje → Respuesta que se comprueba

01 / ECONOMÍA

¿Cómo estudiar una región donde faltan encuestas?

El problema. Un equipo de investigación quiere saber en qué zonas hay mayores carencias económicas. Lo habitual es entrevistar a los hogares para conocer sus condiciones de vida. Pero visitar todas las comunidades cuesta tiempo y dinero, y algunas zonas tienen pocas mediciones.

¿Qué datos se pueden usar? Las imágenes satelitales muestran el territorio desde arriba: caminos, construcciones, cultivos y otros elementos. En ciertas regiones, esos patrones pueden estar relacionados con la infraestructura y las condiciones económicas. La imagen no muestra directamente cuánto gana una familia.

Cómo interviene la red neuronal · paso a paso
  1. Los investigadores reúnen imágenes de lugares donde también tienen encuestas de hogares. Las encuestas aportan una referencia de las condiciones económicas de esas zonas.
  2. Una red neuronal aprende a reconocer patrones visuales de las imágenes. Un sistema de estimación relaciona esas características con los indicadores económicos conocidos.
  3. Después se aplica el sistema a otras imágenes para estimar indicadores de zonas con menos información. Hay que comprobar las estimaciones con datos independientes.

¿Para qué sirve el resultado? Una estimación por zona que puede ayudar a investigar dónde hay más carencias y dónde convendría realizar nuevas mediciones.

Aquí se combinan economía y percepción remota: la primera aporta la pregunta sobre condiciones de vida; la segunda, observaciones del territorio. Es un ejemplo de aplicación entre disciplinas.
Qué puede salir mal

No se debe concluir que una familia es pobre por el aspecto de su vivienda. Las relaciones cambian entre regiones y no prueban las causas de la pobreza.

Caso documentado: Jean et al., Science (2016).

02 / MEDICINA

¿Hay señales de daño en la retina?

El problema. La diabetes puede dañar pequeños vasos sanguíneos de la retina, la capa del fondo del ojo que capta la luz. Ese daño se llama retinopatía diabética. Detectarlo es importante para decidir quién necesita atención especializada.

¿Qué datos se pueden usar? Una cámara obtiene fotografías del fondo del ojo. En ellas pueden aparecer lesiones, como pequeños sangrados. Revisar estas imágenes es una tarea en la que se pueden buscar patrones visuales.

Cómo interviene la red neuronal · paso a paso
  1. Se reúnen fotografías y referencias clínicas que indican si está presente el nivel de enfermedad que se quiere detectar.
  2. La red aprende patrones de las imágenes asociados con esas referencias. No aprende a partir del nombre del paciente: procesa los valores numéricos de la imagen.
  3. Ante una fotografía nueva, el sistema analiza si encuentra señales compatibles con el criterio de detección. También debe comprobarse que la imagen tenga calidad suficiente.

¿Para qué sirve el resultado? Un resultado que ayuda a determinar si la persona debe seguir el proceso de derivación para atención ocular, o si hace falta repetir la captura.

La red procesa una fotografía y produce una detección. La evidencia clínica permite comprobar si esa detección es útil.
Qué puede salir mal

Un error puede dejar pasar una lesión o generar una falsa alarma. El sistema se evalúa para una tarea clínica específica; no revisa por sí solo todas las enfermedades del ojo.

Caso documentado: Abràmoff et al., ensayo clínico de IDx-DR (2018).

03 / ROBÓTICA

¿Cómo sabe un robot qué objeto debe recoger?

El problema. Imagina un brazo robótico frente a una mesa con varios objetos. Una persona le pide que recoja uno. El robot necesita relacionar las palabras de la instrucción con lo que ve y con los movimientos que puede ejecutar.

¿Qué datos se pueden usar? La cámara aporta imágenes de la mesa. La instrucción aporta el objetivo. Las demostraciones robóticas aportan ejemplos de cómo se realizan movimientos para completar tareas.

Cómo interviene la red neuronal · paso a paso
  1. Durante el entrenamiento se combinan ejemplos de imágenes y lenguaje con demostraciones de acciones robóticas.
  2. La red aprende relaciones entre los objetos observados, las instrucciones y las acciones. RT-2 es un sistema documentado que conecta estas tres partes.
  3. Al recibir una nueva imagen e instrucción, el modelo genera una representación de acciones que se utiliza en el control del robot.

¿Para qué sirve el resultado? Acciones para orientar el movimiento del brazo y la pinza, en lugar de una respuesta escrita como la de un chat.

La red conecta lo que el robot ve, lo que se le pide y la acción que debe realizar.
Qué puede salir mal

Reconocer el objeto no garantiza sujetarlo bien. La posición, los obstáculos y la seguridad del movimiento también deben comprobarse.

Caso documentado: Google DeepMind, RT-2 (2023).

04 / MODELOS DE LENGUAJE

¿Cómo puede una red responder con texto?

El problema. Escribes: «Explícame qué es una red de computadoras». Un asistente como ChatGPT utiliza un modelo de lenguaje para generar una respuesta relacionada con tu mensaje y con el contexto de la conversación.

¿Qué datos se pueden usar? Las computadoras no procesan las letras como nosotros: el texto se divide en fragmentos llamados tokens y se convierte en números. Un token puede ser una palabra, parte de ella o un signo.

Cómo interviene la red neuronal · paso a paso
  1. En el entrenamiento, el modelo recibe muchos ejemplos de secuencias de texto. Una tarea fundamental consiste en predecir qué token sigue y ajustar los parámetros cuando la predicción no coincide con el ejemplo.
  2. El modelo aprende relaciones del lenguaje: cómo se combinan fragmentos y cómo cambia una continuación según su contexto. Los modelos tipo GPT emplean una arquitectura de red llamada Transformer.
  3. Cuando escribes una pregunta, el modelo procesa el contexto y genera tokens sucesivamente. Esos fragmentos forman la respuesta que lees.

¿Para qué sirve el resultado? Una secuencia de texto que puede explicar, resumir o proponer código. LLM significa modelo de lenguaje de gran escala.

Sí: los modelos que permiten conversar con asistentes como ChatGPT utilizan redes neuronales profundas. En la página siguiente encontrarás el recorrido completo.
Qué puede salir mal

Una respuesta que suena convincente puede contener errores. Predecir una continuación plausible no certifica que una afirmación sea verdadera.

Caso documentado: OpenAI, GPT-4 Technical Report (2023).

05 / PERCEPCIÓN REMOTA

¿Cómo distinguir bosque, ciudad y agua desde el espacio?

El problema. Un equipo necesita estudiar qué hay en una región: áreas construidas, bosques, cultivos o cuerpos de agua. Recorrer cada lugar sería lento. Puede comenzar observando imágenes tomadas por un satélite.

¿Qué datos se pueden usar? Eso es percepción remota: obtener información de un lugar sin estar en contacto directo con él, mediante sensores. Sentinel-2 es una misión de satélites que observa la Tierra en varias bandas, es decir, rangos de luz, incluidos algunos que no vemos a simple vista.

Cómo interviene la red neuronal · paso a paso
  1. Se reúnen recortes de imágenes y etiquetas que indican el tipo de cobertura que representan. Por ejemplo: un recorte etiquetado como bosque y otro como zona residencial.
  2. La red aprende combinaciones de formas, texturas y valores de las bandas que ayudan a distinguir las clases. EuroSAT es un conjunto de datos utilizado para estudiar esta tarea.
  3. Ante un recorte nuevo, el modelo calcula la clase que le asigna. En esta tarea se clasifica el recorte completo; asignar una clase a cada píxel sería otra tarea.

¿Para qué sirve el resultado? Una etiqueta de cobertura del suelo que puede apoyar inventarios y estudios territoriales. Comparar distintas fechas requiere además imágenes y métodos comparables.

La imagen es el dato de entrada; «bosque», «agua» o «área residencial» son posibles clases de salida.
Qué puede salir mal

Las nubes, la estación del año y los paisajes de otra región pueden cambiar la apariencia de una clase. Las etiquetas deben verificarse con referencias adecuadas.

Caso documentado: Helber et al., EuroSAT.

Qué tienen en común los cinco casos

Una red aprende ajustando sus parámetros a partir de ejemplos. En una imagen puede reconocer patrones visuales; con texto puede aprender relaciones entre fragmentos; en robótica puede relacionar observaciones con acciones.

No todos los ejemplos se resuelven con la misma red. En el laboratorio usaremos una sola neurona y dos entradas para que puedas seguir cada operación.

Pregunta para conversar: elige un caso, explica con tus palabras su problema y nombra una entrada, una salida y un posible error.

Los casos describen investigaciones y sistemas documentados. Las escenas explicativas ayudan a comprender su propósito; esta página no ejecuta esos sistemas. Los enlaces a las fuentes requieren internet.

04 / LLM y redes neuronales

¿Cómo una red neuronal
puede conversar contigo?

Un LLM —Large Language Model, o modelo de lenguaje de gran escala— transforma una secuencia de tokens en predicciones sobre cómo continuarla. Los asistentes como ChatGPT utilizan estos modelos para generar respuestas.

La conexión con el perceptrón: también hay números de entrada, pesos aprendidos y operaciones matemáticas. En un LLM, las representaciones son vectores y se procesan mediante muchas capas. No es una sola neurona que responde 0 o 1.

Del mensaje a la respuesta: el recorrido

1. Texto → 2. Tokens → 3. Vectores + posición → 4. Capas Transformer → 5. Próximo token ↺

Esquema de un modelo generativo de texto típico. Es una explicación de principios públicos; no especifica todos los detalles internos de los modelos disponibles en ChatGPT.

01 / REPRESENTAR

El texto se convierte en números

El tokenizador divide el mensaje en unidades: pueden ser palabras, fragmentos de palabras, signos o espacios combinados con texto. Un token no equivale siempre a una palabra.

Cada token tiene un identificador. El modelo lo relaciona con un embedding: un vector de números aprendido durante el entrenamiento. La información de posición permite distinguir el orden de la secuencia.

Los identificadores funcionan como índices del vocabulario: que uno tenga un número mayor no significa que la palabra sea más importante.

02 / RELACIONAR

La atención combina el contexto

La autoatención calcula relaciones entre las representaciones de los tokens. Usa proyecciones aprendidas, conocidas como consultas, claves y valores, para combinar información del contexto.

Distintas cabezas de atención pueden capturar relaciones diferentes. En la generación causal, el modelo utiliza los tokens anteriores; no dispone de los tokens futuros que aún no ha generado.

«Atención» es el nombre de una operación matemática; no implica atención humana ni conciencia.

03 / TRANSFORMAR

Aquí están las redes neuronales

Los bloques Transformer combinan atención con redes de avance directo —feed-forward— y funciones no lineales. Incluyen además conexiones residuales y normalización.

En esas redes se repite una idea que ya conoces: multiplicar valores por pesos, sumarlos y transformar el resultado. Ahora se hace con vectores y matrices, repetidamente en muchas capas.

La atención también tiene parámetros entrenables. Al entrenar se ajusta el conjunto de parámetros del modelo, no solo una capa final.

04 / GENERAR

Una respuesta se construye paso a paso

La salida del modelo se transforma en puntuaciones para los tokens del vocabulario. Una función llamada softmax las convierte en una distribución de probabilidades.

Un procedimiento de selección elige el siguiente token. Se incorpora al contexto y se calcula el siguiente, hasta una condición de cierre o un límite.

No siempre se elige el token de mayor probabilidad. Las opciones de generación pueden modificar cómo se selecciona entre candidatos.

EXPLORACIÓN INTERACTIVA

Mismo texto inicial, distinto contexto

Observa cómo el contexto podría cambiar los candidatos para continuar «El banco…».

¿Qué significa «candidato»? Es una posible continuación del texto, todavía no seleccionada. Si el texto termina en «El banco…», una opción para escribir a continuación es «ofrece»: quedaría «El banco ofrece…».

Cómo leer la tabla: cada fila propone la siguiente palabra y muestra la frase que se formaría. El porcentaje representa cuánto peso recibe esa opción en esta demostración: 60 % equivale a 60 de cada 100 selecciones en un sorteo con esas probabilidades. No significa que la frase sea 60 % verdadera.

En un modelo real se consideran tokens de un vocabulario amplio. Aquí reducimos las opciones a tres palabras y asignamos porcentajes didácticos que suman 100 %.

Demostración preparada, no un LLM ejecutándose. Los candidatos y porcentajes están escritos para explicar el proceso; no son mediciones de ChatGPT. Se muestran tres alternativas simplificadas como palabras, aunque una tokenización real puede dividirlas.

La diferencia no se debe a cambiar los pesos en ese momento: cambia la entrada que procesa el modelo.

Entrenar y conversar son procesos distintos

ENTRENAMIENTO

Los pesos se ajustan

En el preentrenamiento generativo se comparan predicciones de tokens con los tokens que realmente siguen en los ejemplos. Se calcula una pérdida y, mediante retropropagación y un optimizador, se ajustan los pesos.

Posteriormente pueden aplicarse etapas de ajuste con ejemplos de instrucciones y retroalimentación para mejorar el comportamiento del asistente.

INFERENCIA · USO

Los pesos procesan tu contexto

En una conversación normal, el modelo utiliza parámetros ya entrenados. Leer tu mensaje y responderlo no significa volver a entrenar sus pesos en cada turno.

Tu pregunta y el contexto disponible cambian las representaciones calculadas y la continuación generada. El uso posterior de conversaciones para entrenamiento depende del servicio y sus políticas; es otro proceso.

¿Conversar con un LLM es lo mismo que buscar en internet?

Generar texto usa los parámetros del modelo y el contexto disponible. Un asistente puede incorporar herramientas de búsqueda, archivos o ejecución de código, pero esas herramientas son componentes adicionales. Una respuesta sin búsqueda no debe suponerse verificada en la web.

Pregunta para comprobar que lo entendiste

Si cambias el contexto de «banco» financiero a «banco» de parque, ¿deben cambiar necesariamente los pesos?

No. El mismo modelo puede generar continuaciones diferentes porque procesa entradas distintas. Lo que cambia durante la inferencia son los cálculos y las representaciones del contexto, no necesariamente los parámetros.

05 / Problema de ingeniería

¿Qué incidente
atendemos primero?

Construye y entrena un perceptrón para asignar prioridad a incidentes de un servicio de TI. Comienza con un criterio explícito, conviértelo en datos y comprueba cada decisión.

El escenario

La mesa de ayuda recibe reportes sobre la plataforma académica. Debe distinguir una falla individual de una interrupción que afecta a varios usuarios.

Política del ejercicio: asignar prioridad alta cuando el servicio está inaccesible y el reporte está confirmado por varios usuarios.

Caso didáctico con datos sintéticos. La política se simplifica para poder explicar todos los cálculos; una mesa de ayuda real también considera seguridad, criticidad y otros factores.

Lo que podrás hacer

  1. Identificar entradas, pesos, sesgo y salida.
  2. Calcular una decisión a mano.
  3. Observar cómo se ajustan los parámetros con ejemplos.
  4. Evaluar el modelo y documentar sus límites.

Solo necesitas suma, multiplicación y comparación. Todos los cálculos iniciales utilizan números enteros.

Pregunta de ingeniería: si ya conocemos la política, bastaría programar una condición. Aquí entrenamos una neurona con esa política para comprender cómo un modelo aprende de ejemplos y cómo se verifica su comportamiento.
06 / Anatomía de un perceptrón

Datos → cálculo → decisión.

Un perceptrón es una unidad de cálculo que combina entradas con pesos, añade un sesgo y aplica una regla de decisión. Puede representar una frontera lineal entre dos clases.

Diagrama del modelo de prioridad

Cómo leer cada elemento del dibujo

Entradas x₁ y x₂

Hechos codificados como 0 o 1. Deben tener una definición consistente en todos los reportes.

Pesos w₁ y w₂

Multiplicadores que controlan cuánto aporta cada entrada a la suma. Durante el entrenamiento se ajustan.

Sesgo b

Desplaza la frontera de decisión. Si b = −3, la suma de las contribuciones debe alcanzar 3 para producir salida 1.

¿Y la red neuronal? Esta práctica estudia una sola neurona. Al conectar varias neuronas y capas con activaciones no lineales se pueden representar relaciones más complejas.
Del caso real a nuestro modelo introductorio

En los casos anteriores, la red aprende representaciones de imágenes, señales o texto. En este laboratorio las dos entradas ya están definidas como indicadores binarios. Empezamos así para que puedas verificar cada operación antes de estudiar redes de varias capas.

07 / Ejemplo resuelto

Un reporte, explicado completo.

Varios estudiantes confirman que no pueden acceder a la plataforma: x₁=1 y x₂=1. La política espera prioridad alta: y=1.

El perceptrón del reporte: sigue la parte resaltada

Pulsa «Calcular siguiente paso» para ejecutar una etapa a la vez. En cada etapa verás la fórmula y el resultado, y se resaltará el bloque correspondiente del dibujo.

En una pantalla pequeña, desliza el dibujo hacia los lados para seguir todas las etapas.

Una configuración que cumple la política

w₁ = 2   w₂ = 2   b = −3

Cada señal aporta 2 puntos. Para clasificar como alta se requieren al menos 3 puntos. Una sola señal aporta 2; ambas aportan 4.

Estos valores fueron elegidos para explicar la regla. No son mediciones ni probabilidades. En el entrenamiento partiremos desde cero y obtendremos otros valores válidos.

¿De dónde sale z?

z es el nombre que damos al resultado de la suma interna del perceptrón. No es otro dato del reporte: se calcula usando las entradas, sus pesos y el sesgo.

  1. Multiplica x₁ por su peso w₁.
  2. Multiplica x₂ por su peso w₂.
  3. Suma ambos aportes y añade el sesgo b.
z = w₁ × x₁ + w₂ × x₂ + b
En este ejemplo: z = 2 × x₁ + 2 × x₂ − 3

Ejemplo con x₁=0 y x₂=1:
z = 2×0 + 2×1 − 3
z = 0 + 2 − 3 = −1.

Después aplicamos la activación: como −1 es menor que 0, la salida es ŷ=0, prioridad normal. z es la suma previa; ŷ es la decisión final. La letra z solo identifica esa suma.

Lee la tabla de izquierda a derecha: entradas → operación → valor de z → prioridad según el umbral z≥0.

Un contraste necesario: si solo una persona no puede acceder (x₁=1, x₂=0), z=2+0−3=−1 y ŷ=0. «Normal» significa atender por el flujo ordinario de esta política; no significa ignorar el reporte.
¿Por qué no usar 0.5 o −1.5?

Los parámetros de una red pueden tener decimales, pero no son obligatorios. En esta introducción usamos enteros para que puedas interpretar cada aporte. Multiplicar todos los pesos y el sesgo por el mismo número positivo conserva la decisión del perceptrón.

No existe una única combinación correcta: w₁=1, w₂=1 y b=−2 también reproduce esta tabla, porque z=0 ya produce salida 1. Lo que importa es verificar las decisiones y explicar el modelo.

09 / Aprendizaje supervisado

Ahora los ejemplos ajustan el modelo.

Entrenar significa comparar una predicción con una etiqueta esperada y modificar los parámetros cuando hay error. Aquí puedes observar cada ajuste.

Regla de actualización del perceptrón:
error = y − ŷ
w₁ nuevo = w₁ + η × error × x₁
w₂ nuevo = w₂ + η × error × x₂
b nuevo = b + η × error
En este laboratorio η=1. Es el tamaño del ajuste y se mantiene fijo; permite trabajar con enteros.
El primer error, antes de pulsar un botón

Al iniciar, w₁=0, w₂=0 y b=0. Para el primer ejemplo (0,0), z=0 y el modelo predice ŷ=1, pero la etiqueta es y=0.

Error = 0−1 = −1. Ambos pesos permanecen en 0 porque las entradas valen 0. El sesgo cambia: b nuevo = 0 + 1×(−1) = −1. El modelo corrige ese ejemplo.

La política B representa un cambio de criterio del equipo de soporte. XOR es solo una prueba matemática de los límites del modelo. Cambiar de opción reinicia el entrenamiento.

Errores al terminar cada pasada

Si XOR no se resuelve, ¿falló el programa?

Una sola neurona con esta activación separa las clases mediante una línea. En XOR, las clases iguales quedan en esquinas opuestas: ninguna línea las separa. Más pasadas no resuelven esa limitación. Se puede representar XOR con varias neuronas, una capa oculta y activaciones no lineales.

Alcance de la comprobación: usamos las cuatro combinaciones binarias posibles, tanto para entrenar como para comprobar la tabla completa. No es una evaluación independiente de generalización. En un proyecto real habría que separar datos de entrenamiento y prueba, y evaluar casos representativos.
