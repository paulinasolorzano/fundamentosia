02 · Fundamentos

Seis conceptos para entender un LLM

Términos fundamentales para trabajar con modelos de lenguaje de gran tamaño.

01
Token
Unidad que el modelo procesa. Puede ser una palabra, fragmento o signo.
02
Prompt
Instrucción o entrada del usuario. Ejemplo: «Resume este reglamento».
03
Contexto
Información disponible en la petición. Su ventana tiene un límite de tokens.
04
Parámetros
Valores numéricos que el modelo aprende durante su entrenamiento.
05
Modelo
Red neuronal entrenada que usa sus parámetros para producir una salida.
06
Inferencia
Uso del modelo ya entrenado para generar una respuesta a una entrada.
03 · Proceso

Cómo genera una respuesta

El proceso autorregresivo de un LLM, paso a paso. Una respuesta fluida puede contener errores.

01

Tokenización

La entrada se convierte en una secuencia de tokens numéricos.

02

Procesamiento

La red utiliza el contexto y sus parámetros aprendidos.

03

Selección

Calcula probabilidades y selecciona el siguiente token.

04

Repetición

Añade el token y continúa hasta terminar la respuesta.

08 · RAG

Respuestas apoyadas en documentos

RAG combina recuperación de información con generación de texto. Consultar documentos agrega contexto sin reentrenar el modelo.

1. Pregunta

«¿Cómo solicito una beca?»

↓

2. Recuperación

El sistema busca fragmentos del reglamento vigente.

↓

3. Generación

El LLM recibe la pregunta y los fragmentos como contexto.

↓

4. Revisión

La respuesta cita la fuente. Si falta evidencia, lo indica.

09 · Caso 1

Asistente universitario

Responder dudas sobre becas con el reglamento vigente.

Fragmento del reglamento
«Artículo 8. La solicitud requiere identificación y constancia de inscripción, antes del 15 de noviembre».
Pregunta del estudiante
«¿Qué promedio mínimo necesito para solicitar la beca?»
Respuesta correcta

El fragmento indica los documentos y la fecha, pero no especifica promedio mínimo. Consulta la convocatoria completa o servicios escolares.

Criterio: cada afirmación tiene respaldo o reconoce la falta de datos
10 · Caso 2

Asistente de programación

Consultar documentos vigentes

Evaluar casos diversos

Minimizar datos y limitar acceso

Ejercicio 1 · Investigación

Explora el mundo de los LLMs

Investiga y documenta al menos 3 modelos de lenguaje diferentes. Comprende qué hace cada uno y para qué sirve.

1
Busca información sobre estos LLMs: ChatGPT (OpenAI), Claude (Anthropic), Gemini (Google), Llama (Meta), Mistral. Puedes agregar otros que encuentres.
2
Para cada modelo, identifica: quién lo creó, qué lo hace especial, qué tareas resuelve mejor y si es gratuito o de pago.
3
Busca un caso de uso real donde se haya aplicado cada modelo (noticias, artículos, ejemplos de empresas o universidades).
4
Compara al menos dos modelos: ¿en qué se parecen? ¿en qué son diferentes? ¿cuándo usarías uno u otro?

Ejercicio 2 · Análisis

Elige la herramienta correcta

Aprende a identificar qué tipo de IA o LLM es apropiado para cada problema. No todas las tareas necesitan un LLM.

1
Analiza estos 5 problemas y decide qué método usarías: LLM, buscador tradicional, regresión, clasificación, reglas o grafos.
2
Problemas a resolver: (a) Resumir un reglamento de 50 páginas, (b) Predecir el precio de una casa, (c) Detectar spam en correos, (d) Encontrar la ruta más corta entre dos ciudades, (e) Explicar qué es una red neuronal.
3
Justifica cada elección en 2-3 frases: ¿por qué ese método y no otro? ¿qué ventajas tiene?
4
Identifica un problema de tu vida diaria (universidad, trabajo, hogar) y propón una solución con IA. Explica qué tipo de IA usarías y por qué.
5
Prueba un LLM real (ChatGPT, Claude, Gemini, etc.) con una pregunta sencilla. Documenta: ¿qué le preguntaste? ¿qué respondió? ¿fue útil? ¿qué le cambiarías al prompt?

Ejercicio 3 · Diseño

Diseña tu propio asistente con IA

Aplica todo lo aprendido diseñando un asistente inteligente para un problema real. Piensa como un ingeniero de IA.

1
Elige un problema de tu universidad, comunidad o vida diaria que podría resolverse con un asistente de IA (ej: tutoría, soporte técnico, trámites, búsqueda de información).
2
Define el usuario: ¿quién lo usaría? ¿qué necesita resolver? ¿con qué frecuencia?
3
Diseña el flujo: ¿qué recibe el asistente? ¿de dónde obtiene la información? ¿qué parte hace el LLM y qué parte hace otro sistema?
4
Escribe 3 prompts de ejemplo que usaría el asistente. Incluye tarea, contexto, criterios y formato. Prueba al menos uno con un LLM real.
5
Identifica riesgos: ¿qué puede fallar? (alucinaciones, datos desactualizados, sesgos, privacidad). Propón un control para cada riesgo.
6
Define cómo verificarías que el asistente funciona bien. ¿Qué prueba harías? ¿qué respuesta esperarías?
Entregable para la próxima clase

Una ficha de diseño (1 página) con: nombre del asistente, problema que resuelve, usuario, flujo de trabajo, 3 prompts de ejemplo, riesgos y controles, y prueba de verificación. Prepárate para presentar tu propuesta en 3 minutos y responder preguntas del grupo.

Resumen final

Lo que debes saber al terminar esta unidad

Conceptos clave

Token, prompt, contexto, parámetros, modelo, inferencia. Sabes qué significa cada uno y cómo se relacionan.

Cómo funciona

Entiendes el proceso de tokenización, procesamiento, selección y repetición. Sabes que un LLM genera texto, no "piensa".

Cuándo usarlo

Puedes identificar tareas apropiadas para un LLM y distinguirlas de problemas que requieren otros métodos (regresión, clasificación, grafos).

Limitaciones

Conoces los riesgos (alucinación, sesgo, privacidad) y sabes aplicar controles para reducirlos.
